# 原典与现代释读的层级

- 第一层：十三篇通行原文，来自开放古籍电子数据集；现代标点不是古籍原始形态。
- 第二层：编辑性句界，以「。！？；」切分，431个阅读单元；段落重组与原文字串完全一致。
- 第三层：431条独立编写的现代白话**史义释读**，帮助理解历史概念，**不是逐字训诂，也非可执行军事操作指南**。
- 第四层：现实决策类比，仅适用于非暴力、合法、尊重事实和权利的场景。

古书原始字句属于公有领域。电子整理、标点和现代注释可能涉及不同许可；引用和转载时应核查来源，不能把他人的现代译文挪为本项目原创。

高风险校勘：始计 / 计篇篇名；军形篇传本与出土简文「守则不足，攻则有余」的异文；九地篇句序；用间篇「因间 / 乡间」不同读法。见 docs/TEXTUAL-SOURCES.md。

译意应保持谦逊：有争议的术语或历史推测必须标注为解释，不能说成权威定论。
