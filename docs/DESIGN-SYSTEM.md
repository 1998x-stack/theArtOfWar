# 设计系统：青铜 · 深墨 · 宣纸

设计目标不是军事风格化或暴力美学，而是以东方古籍语言表现审慎、留白、判断与历史深度。借鉴高端现代网站的滚动节奏与微动效，但保留原创视觉设计。

| 正文 | #efece1 | #213334 |
| 内容背景 | #192628 | #eae6d9 |
| 次级文字 | #bac5bd | #5d6c66 |
| 青铜强调 | #d1ad74 | #876438 |

书名和古文使用系统宋体/衬线回退，控件使用系统无衬线字体，无需分发商业字体。

页面叙事：静态标题与日轮水墨主视觉 → 慎、全、知三条思想线索 → 静读引句 → 十三篇目录 → 逐句阅读室。装饰运动包含缓慢浮动、环线旋转和进入视口后的渐显。

Desktop目录三列、阅读室左侧导航加右侧**单列**古文/释义；Mobile目录两列、导航可横滚，句子依旧上下叠置。系统设置减少动画时，关闭非必要动画。焦点、按钮状态、空结果、边界禁用均须清晰。
