# 测试验收与发布标准

## 自动化

使用 npm test、npm run build。测试检查：
- 13篇编号唯一且连续，83段原文存在；
- 全书431条独立原文/史义映射，解释无空字段；
- 逐段拼回时字符完全不变、句号ID稳定；
- 原文和译意按钮在DOM中的关键绑定；
- 译文默认hidden，单句独立可展开；
- 静态构建dist包含所有数据、HTML、CSS和SVG。

自动化不代表古籍语义逐字正确、无障碍完整合规或Pages已成功上线。

## 手工测试矩阵

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 全书 | 清空搜索 | 显示13篇 |
| 搜索 | 搜索「知彼知己」 | 命中《谋攻篇》 |
| 逐句 | 点开第2句译意 | 仅该句展开 |
| 重置 | 切换章节再返回 | 所有译意隐藏 |
| 控件 | 「全部收起」 | 所有展开译意关闭 |
| 分享 | 刷新#chapter-13 | 正确显示第十三篇 |
| 收藏 | 收藏后刷新 | 当前浏览器保留 |
| 手机 | 375px与430px测试 | 原文和译意始终上下 |
| 键盘 | Tab/Enter/Space及搜索/键 | 可无鼠标使用 |
| 动效 | 设置减少动画 | 装饰运动停止 |
| 站点 | GitHub Actions、浏览器访问 | 资源无404，无运行异常 |

发布失败须先确认是代码、CI、Pages配置还是浏览器访问问题，不能混为一谈。
