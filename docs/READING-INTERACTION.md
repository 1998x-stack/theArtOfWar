# 逐句阅读交互规格

每句只使用一个垂直阅读卡：古文在上 → 「点击见义」按钮 → 对应现代史义释读在下。全宽和手机均保持上下结构。

初始：古文可见，释义节点设置hidden=true，aria-expanded=false。

点击自身按钮：只展开对应释义，aria-expanded切为true。重复点击：收起自身。「全部收起」恢复当篇全部隐藏。切换章节：重新创建所有句卡，因此全部隐藏。字体变化不应改变展开状态。

每个按钮通过aria-controls绑定唯一释义节点，键盘Enter和Space可用。译意的隐藏应从可访问树与视觉布局中同时生效，不仅用模糊滤镜假遮挡。

验收：13篇431句、首篇和末篇深链、随机句子的独立状态、375px手机、减少动画模式、屏幕阅读器的状态识别。
