# 原典来源与校勘边界

## 当前文本

本仓库为《孙子兵法》十三篇**现代简体标点阅读版**，并非专业影印校勘定本。文本初始录入依据公开古籍JSON，仅取古代原文，不沿用第三方现代译文。

- [hanzhaodeng/chinese-ancient-text：孙子兵法.json](https://github.com/hanzhaodeng/chinese-ancient-text/blob/master/孙子兵法.json)：本项目初始化的电子文本来源。
- [维基文库《孫子兵法》](https://zh.wikisource.org/wiki/孫子兵法)：通行十三篇和异文交叉对照。
- [中国哲学书电子化计划](https://ctext.org/art-of-war/zhs)：辅助阅读检索，不代替固定校本。
- 相关历史研究还可参考银雀山汉简《孙子兵法》出版整理本，核对时需标注具体版本和页码。

本项目原文共13篇、83个电子整理段落；按「。！？；」编辑性句界拆成431条。所有分句重新拼接，必须逐字恢复原始段落。431条现代文本系编辑性历史释读，**并不构成逐字训诂定本，也不提供现实危险行为操作指引**。

## 已知异文与编辑处理

1. 第一篇流传篇名有「计」「始计」之差别，当前导航使用「始计篇」。
2. 第四篇源JSON含「（竹简为：守则有余，攻则不足）」编者括注；此括注已从原文正文剥离，原读与异文待据出版校本核查。
3. 第六篇「无常势」一类用字需与具体传本和出土材料核对。
4. 第十一篇断句及古代地形术语复杂，不应把编辑句读当作唯一标准。
5. 第十三篇「因间 / 乡间」与其他异文关系需要逐字比对。

## 文献审查程序

固定电子修订版或出版书目 → 逐字核对 → 注文与正文分离 → 标点与原字分离 → 保存异文而不覆盖 → 第二审阅者复核 → 记录PR和校对状态。自动测试只验证结构，不证明古文真实出处或释义的权威性。

古代原作属公有领域，现代整理文本、译注和影印图片的授权可能不同，需分别核实。
