# 以兵家慎思解决现实问题

此Skill不是战争技能，而是从《孙子兵法》提取慎战、全胜、庙算、知彼知己、利害相参、应变等可用于日常的思辨框架。

建议流程：确认真实问题与边界 → 分清已知、未知和风险 → 选择贴切且真实的原文短句，标篇名 → 用平实中文解释古代语境及其现代适用界限 → 提出1–3项具体、合法、非暴力行动。

### 例：项目上线风险

引经：「智者之虑，必杂于利害。」——《孙子兵法·九变篇》。

释读：聪明的决策者同时考虑行动的收益与损失。

实践：列出不可逆风险，制定上线停止条件和回滚机制，不因压力忽视用户安全。这是现代应用类比，不是古书能直接证明技术方案。

不能移植的内容：古代战争中的暴力、火攻、情报欺诈与胁迫手段。现实中必须遵守法律、隐私、诚实与安全原则，不提供这些行为的可执行教程。
