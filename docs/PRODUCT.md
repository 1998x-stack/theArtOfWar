# 产品愿景与边界

产品定位：以现代东方美学呈现《孙子兵法》十三篇古典阅读，并将其慎战、庙算、保全、风险评估等理念用于**非暴力、合法的现实决策**。

## 用户任务

首次读者可在一分钟内找到一篇并开始阅读。深入读者先读原文，点击该句才显示对应史义释读；切篇后重新遮挡。实践用户将AI Skill用于学习、项目管理、协作、冲突降级，但不能照搬古代战争操作。

## 当前范围

13篇原文、431个句级阅读单元、点击见义、搜索、标签、书签、深浅配色、字号、深链、阅读进度、非暴力的AI Skill、CI和Pages工作流。

不做真实作战模拟、危险行为操作指令、人员监视或秘密情报方案。不声称实现了学术定本。

## 成功标准

结构完整；原文不丢字；译意点击前完全隐藏；页面一列上下阅读；手机与桌面均可操作；CI与Pages真实状态可核查。
